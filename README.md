### What I build

- A chain of skills: requirements → test cases → execution → defects → automated-test review
- Checklists covering UI states, payloads, responsive layouts and cross-browser behaviour
- A catalogue of review rules for Playwright tests, derived from the official docs and real project practice
- Commit gates: a hook blocks the commit until a fresh green run exists
